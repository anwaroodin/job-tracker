# Fonts

Used by the CV PDF (`lib/cv-pdf/`). Each design loads only its own fonts.

- **TeX Gyre Termes** (regular, italic, bold, bold italic and bold small caps), for the Classic design. Copyright GUST e-foundry, distributed under the [GUST Font License](https://www.gust.org.pl/projects/e-foundry/licenses). Source: [TeX Gyre Termes](https://www.gust.org.pl/projects/e-foundry/tex-gyre/termes).
- **IBM Plex Serif** (regular, semibold, bold), for the Onyx design. SIL Open Font License 1.1: `OFL-ibmplexserif.txt`.
- **Inter** (regular, bold) and **Montserrat** (semibold), for the Persian design. SIL Open Font License 1.1: `OFL-inter.txt`, `OFL-montserrat.txt`.

The OFL fonts are the static files Google Fonts serves.
